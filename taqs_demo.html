Task-Aware Query-Anchored Selection

Step 1: Data Upload CSV
Data Requirements: Please upload a preprocessed feature matrix file (CSV recommended). The Task dataset is the query anchor set, and the Train dataset is the candidate training pool. The last column is the target variable y, and the remaining columns are numerical/categorical features. Note: Raw data (e.g., SMILES, images, text) must first be featurized and vectorized into a "samples × features" matrix before being passed in as CSV. The algorithm does not directly process raw unstructured data. Computation is performed server-side with Python + NumPy.
