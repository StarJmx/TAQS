Pain prediction dataset Emphatica E4
Physiological Time-Series Dataset that can be used for Pain Prediction

About Dataset
This dataset comprises multimodal physiological and motion signals collected using an Empatica wearable device, designed to analyze and predict subjective pain levels in individuals. The data is recorded in a time-series format, where each row represents synchronized sensor readings captured at specific time intervals for a subject.

The dataset includes both physiological signals and motion-based features, enabling a comprehensive understanding of the user’s physical and emotional state.

Features Included

person_ID→ Unique identifier for each subject

acc_x, acc_y, acc_z → 3-axis accelerometer data capturing body movement

eda (Electrodermal Activity)→ Measures skin conductance, indicating stress and emotional arousal

bvp (Blood Volume Pulse)→ Reflects cardiovascular activity and blood flow changes

hr (Heart Rate) → Beats per minute, indicating physiological response

temp (Skin Temperature) → Provides information about peripheral body temperature

pain_scale → Subjective pain rating reported by the individual (e.g., 0–10 scale)
